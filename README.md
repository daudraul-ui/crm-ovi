# CRM OVI

CRM-система для управления продажей и монтажом остекления холодильного оборудования.

## Технологии
- Python / Django
- PostgreSQL
- Django REST Framework
- Docker Compose

## Разработка
Этап A — базовая архитектура CRM.

Бизнес-процессы БП-01 и БП-02 будут реализованы на следующих этапах.
